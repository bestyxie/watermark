# 图片水印工具 · 规格书

状态：已通过 grilling 确认，可进入实现。
最后更新：2026-10-28

## 1. 目标

一个**纯浏览器本地**的图片水印工具：导入单张或多张图片，用同一套平铺文字水印参数实时预览，并按原格式导出。

成功标准：

- 用户不离开页面即可完成「导入 → 调参 → 预览 → 导出」。
- 50 张图片的批次不会让页面崩溃或长时间无响应。
- 任何图片像素都不离开设备。

## 2. 非目标（本期明确不做）

- 单个水印的拖拽定位（只做平铺）。
- 描边、阴影、图片 Logo 水印。
- 自定义字体上传、网络字体。
- GIF / 视频 / PDF / HEIC / AVIF / SVG。
- 服务端、账号、云端存储、分享链接。
- 参数预设管理、撤销栈（只保留“恢复默认”）。
- 多语言（仅简体中文）。
- 水印去除、自动检测、版权追踪。

## 3. 技术基线

- React + Vite + TypeScript（strict）。
- 状态：Zustand（batch / spec / preview / export 四个 slice）。
- ZIP：`fflate`。
- 样式：CSS Modules + CSS 变量；不引入 UI 组件库。
- 测试：Vitest（几何与规格逻辑）+ Playwright（主流程）。
- 部署：纯静态产物，可放 Vercel / Netlify / GitHub Pages。
- 浏览器：Chrome / Edge / Firefox 最近两个版本，Safari ≥ 16.4。

## 4. 界面结构

### 桌面（≥ 1024px）：三栏工作台

```text
┌────────────┬──────────────────────────┬─────────────────┐
│ 图片列表    │        大图预览           │   水印参数       │
│ 缩略图+状态 │  (适应屏幕 / 1:1 / 平移)   │   文本/字体/...  │
│ 导入/清空   │                          │   恢复默认       │
├────────────┴──────────────────────────┴─────────────────┤
│              导出：打包 ZIP | 逐张下载 | 进度            │
└─────────────────────────────────────────────────────────┘
```

### 平板（640–1023px）

- 两栏：图片列表 + 预览。
- 参数面板收进右侧抽屉，按钮固定在预览右上角。

### 手机（< 640px）：功能对等，布局折叠

- 纵向单栏：预览在上，缩略图横向滚动条在下。
- 参数放进**底部抽屉**（可上拉展开、下拉收起）。
- 导出操作固定在底部操作条。
- 所有桌面能力必须可用；触摸目标 ≥ 44×44px。
- 双击（double-tap）切换 1:1；放大后单指平移。

## 5. 功能需求

### FR-1 导入

- 三种入口：点击选择、拖拽到页面任意位置、`Ctrl/Cmd+V` 粘贴。
- 接受 JPG / PNG / WebP；单张 ≤ 30 MB；单批 ≤ 50 张。
- 按 EXIF 方向摆正；其余元数据丢弃。
- 超限、类型不符、解码失败的文件不得进入批次，并给出中文错误提示。
- 同名文件允许共存，以内部 `id` 区分。
- 空状态显示引导文案和“选择图片”按钮。

### FR-2 批次管理

- 列表项：缩略图（带水印）、文件名、尺寸、状态（解码中 / 就绪 / 失败）。
- 点击列表项切换当前预览图。
- 支持移除单张、清空全部（多张时二次确认）。
- 不提供排序、分组、逐图参数覆盖。

### FR-3 参数编辑

控件与取值范围严格对应 `glossary.md` 的参数表。

- 文本：多行 textarea，最多 500 字符，支持 `\n`。
- 字体：无衬线 / 衬线 / 等宽。
- 字号：按短边百分比调节（1%–30%），同时显示当前图换算后的 px。
- 颜色：原生取色器 + 十六进制输入，双向同步。
- 不透明度：滑块 0%–100%。
- 角度：滑块/数字输入 -180°–180°，顺时针为正。
- 间隔：滑块 0–5 倍字号，步长 0.1。
- “恢复默认”：一键回到默认参数，并覆盖本地持久化值。
- 文本为空或仅空白：预览显示提示，导出按钮禁用。
- 参数越界时钳制到合法范围，不抛错。

### FR-4 实时预览

- 当前选中图显示在预览区，默认“适应屏幕”。
- 双击/双击触摸切换 1:1；放大后支持拖拽平移；提供“适应屏幕”复位。
- 显示原图尺寸与当前缩放比例。
- 参数变化后 **≤ 120ms** 内更新预览（防抖 + rAF）。
- 批次中所有已就绪缩略图同步重绘；不可见缩略图可延迟到进入视口再渲染。
- 预览使用降采样位图（长边 ≤ 2048），导出使用原图分辨率。

### FR-5 导出

- 单张：直接下载。
- 多张：两个并列按钮——“打包 ZIP”和“逐张下载”。
- 导出格式跟随原图：JPEG→JPEG、PNG→PNG、WebP→WebP。
- 有损格式提供质量滑块 0.60–1.00，默认 0.92；PNG 不显示质量。
- 文件名：`<原名>-watermarked.<扩展名>`；重名自动追加 `-1`、`-2`。
- ZIP 文件名：`watermarked-<YYYYMMDD-HHmmss>.zip`，包内平铺，不建子目录。
- 导出中显示进度（已完成/总数 + 当前文件名），可取消。
- 取消后：ZIP 不产出文件；逐张模式下已触发的下载保留。
- 结束后汇总“成功 N / 失败 M”，失败项列出原因并可“重试失败项”。
- 导出开始即冻结 Spec 快照；导出期间的改参只影响下一次。
- 不保留 EXIF/GPS，方向已烧录进像素。
- 若浏览器不支持 WebP 编码，回退为 PNG 并明确告知。

### FR-6 持久化

- 仅持久化 `WatermarkSpec`，键名 `watermark:spec:v1`，写入防抖 300ms。
- 启动时校验并钳制；损坏或版本不符时回退默认值。
- 素材、缩放状态、导出设置不持久化。

### FR-7 隐私

- 页面不得发起携带图片数据的网络请求。
- 首屏显示“图片不会上传，全部在本机处理”。
- 默认不接入任何分析/埋点 SDK。

## 6. 非功能需求

| 编号 | 要求 |
| --- | --- |
| NFR-1 | 2048px 预览图的参数更新，p95 ≤ 120ms（中端笔记本）。 |
| NFR-2 | 主线程单次阻塞 ≤ 200ms；批量导出在 Worker 中执行。 |
| NFR-3 | 导入 20 张 5MP 图片并生成缩略图 ≤ 3s；期间 UI 可交互。 |
| NFR-4 | 50 张批次下，内存中不同时保留超过 2 张全分辨率位图。 |
| NFR-5 | 所有用户可见错误为简体中文，包含“哪张图、为什么、怎么办”。 |
| NFR-6 | 键盘可完成导入、调参、切换图片、导出；进度用 `aria-live` 播报。 |
| NFR-7 | 支持系统级减少动态效果（`prefers-reduced-motion`）。 |
| NFR-8 | 无图片数据上报；除静态资源外无网络依赖。 |

## 7. 验收标准

### AC-1 单张完整流程

Given 用户打开空工作台
When 导入一张 3000×2000 JPEG，输入“机密”，设置红色、40%、-45°、1.5 倍间隔、5% 字号并导出
Then 预览在 120ms 内更新；导出得到同尺寸、同格式的 `原名-watermarked.jpg`；四角均有水印且边缘可截断；文件不含 EXIF。

### AC-2 批量共享参数

Given 批次中有 3 张不同尺寸图片
When 修改角度为 -30°
Then 3 张缩略图与当前大图同时更新，且水印视觉大小与角度一致（按短边等比）。

### AC-3 上限与错误

Given 用户一次选择 51 张图片
When 导入
Then 仅前 50 张进入批次，提示“最多 50 张，已忽略 1 张”；超过 30 MB 的单张被拒绝并列出文件名。

### AC-4 失败隔离与重试

Given 批次中有一张损坏图片
When 导出 ZIP
Then 其余图片正常产出；结果汇总显示失败 1 张及原因；点击“重试失败项”只重跑该张。

### AC-5 取消

Given 正在导出 30 张图片
When 点击取消
Then 停止调度后续图片，ZIP 不产出，界面回到可操作状态。

### AC-6 持久化

Given 用户把水印改成白色、20%、60°
When 刷新页面
Then 参数恢复；批次与预览缩放不恢复。

### AC-7 移动端功能对等

Given 用户在 375px 宽的手机浏览器打开
When 完成导入、调参、双击 1:1 查看、导出
Then 所有功能可用，无横向溢出，触摸目标不小于 44px。

### AC-8 分辨率无关

Given 同一 Spec
When 分别以 800px 和 3200px 渲染
Then 水印数量、位置比例、角度一致；字号与间隔按短边等比缩放。

## 8. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| Safari 的 OffscreenCanvas/Worker 能力差异 | 特性检测；不可用时降级到主线程顺序导出。 |
| 50 张大图导致内存峰值 | 只持有 File，按需解码；导出并发 ≤ 2；及时 `close()` 位图。 |
| 极端参数产生海量 Tile | 预估 Tile 数；超过 20,000 时提示“水印过密”并阻止导出。 |
| 超长单行文本导致 Tile 宽于画布 | 预览提示“水印过大”，仍允许调整；导出不禁用。 |
| WebP 编码不支持 | 回退 PNG 并告知。 |
| iOS 下载多文件受限 | ZIP 走系统分享/下载；逐张下载给出兼容提示。 |
| Canvas 重编码造成色彩偏移 | 接受；不承诺像素级色彩一致。 |
| 字体度量跨平台差异 | 预览与导出在同一设备完成，天然一致；不承诺跨设备像素一致。 |

## 10. 测试

### 单元测试

- `pnpm test`：Vitest，覆盖平铺几何、参数钳制、颜色解析、命名规则、文件校验。
- `pnpm typecheck`：同时检查应用代码与 e2e 代码的 TypeScript 类型。

### 端到端测试

- 首次运行安装浏览器：`pnpm e2e:install`。
- 运行：`pnpm e2e`；交互模式：`pnpm e2e:ui`。
- Playwright 会自动在 `127.0.0.1:4173` 启动 Vite，测试产物写入 `test-results/`（已忽略）。
- 覆盖场景：单张 / 批量导入、ZIP 与逐张导出、格式保持、重名去重、PNG 质量控件、非法与损坏文件隔离、空文本禁用导出、实时预览更新、参数持久化、1:1 切换、取消导出、移动端参数抽屉、OffscreenCanvas 降级。
