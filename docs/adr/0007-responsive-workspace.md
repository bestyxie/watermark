# ADR-0007：响应式三栏工作台

- 状态：Accepted
- 日期：2026-10-28

## 背景

桌面端需要“图片列表 + 大图预览 + 参数面板”的三栏工作台；同时用户要求移动端“同等体验”。在 375px 宽度下三栏不可能同时成立，必须把“同等体验”定义成可验收的行为。

## 决策

“功能对等”指：移动端可以完成导入 → 调参 → 预览 → 导出的全部流程，且所有参数可调；不要求布局与桌面一致。

### 断点

| 宽度 | 布局 |
| --- | --- |
| ≥ 1024px | 三栏：列表 240px / 预览自适应 / 参数 320px |
| 640–1023px | 两栏：列表 + 预览；参数为右侧抽屉 |
| < 640px | 单栏：预览 + 横向缩略图条；参数为底部抽屉；导出为底部固定操作条 |

### 移动端交互

- 参数抽屉支持上拉展开、下拉收起，展开时预览仍可见一部分。
- 缩略图横向滚动，当前项自动滚入视口。
- 双击（double-tap）切换 1:1；放大后单指平移；提供“适应屏幕”复位。
- 所有触摸目标 ≥ 44×44px。
- 导出按钮固定在安全区上方，适配 `env(safe-area-inset-bottom)`。

### 桌面端交互

- 双击切换 1:1；滚轮缩放作为增强（不强制）。
- 拖拽文件到页面任意位置触发导入。
- 键盘：Tab 遍历控件；快捷键 `Cmd/Ctrl+V` 粘贴；`Esc` 关闭抽屉/取消缩放。

## 理由

- 三栏在桌面上信息密度最高，符合工具型产品的使用习惯。
- 移动端折叠为“预览优先”，参数按需展开，避免把桌面布局硬塞进窄屏。
- 明确“功能对等”而不是“布局一致”，避免无休止的适配。

## 后果

- 需要维护三套布局的 CSS 与少量交互分支，测试需覆盖三个断点。
- 底部抽屉与固定操作条会占用垂直空间，预览区需动态计算高度。
- 移动端批量导出可能受系统下载/分享限制，需给出兼容提示。
- 不承诺移动端与桌面端像素级一致的预览，只承诺功能与参数一致。
