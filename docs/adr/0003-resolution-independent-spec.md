# ADR-0003：水印规格与分辨率解耦

- 状态：Accepted
- 日期：2026-10-28

## 背景

实时预览不能总是用原图渲染（大图会卡），但导出必须用原分辨率。如果把字号、间隔存成“当前预览图上的像素值”，切换预览分辨率或导出时就会错位。

## 决策

`WatermarkSpec` 只存**相对量**：

- `sizeRatio` = 字号 / 图片短边
- `gapRatio` = 间隔 / 字号

渲染时按目标画布尺寸派生绝对像素：

```ts
const f = spec.sizeRatio * Math.min(width, height);
const gap = spec.gapRatio * f;
```

预览渲染（长边 ≤ 2048）与导出渲染（原分辨率）调用**同一个布局函数**，仅传入不同的 `width/height`。

UI 上仍可按当前图换算并显示 px，但该 px 值不是存储值。

## 理由

- 批量中图片尺寸各异，相对量能保证视觉一致。
- 预览与导出使用同一条公式，天然对齐。
- Spec 可序列化、可持久化，不依赖任何一张具体图片。

## 后果

- 由于字体度量不是严格线性，不同分辨率下文字宽度会有亚像素级差异；布局比例仍然一致。
- 需要一组“分辨率无关”的测试：同一 Spec 在 800px 与 3200px 下的水印数量、位置比例、角度一致。
- 如果未来要支持“固定毫米/固定像素”的水印，需要新增字段并迁移，而不是改变现有字段语义。
- 用户不能直接输入“字号 24px”作为持久值；输入会被换算为比例。
