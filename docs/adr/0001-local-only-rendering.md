# ADR-0001：纯浏览器本地渲染，无后端

- 状态：Accepted
- 日期：2026-10-28

## 背景

水印工具处理的是用户照片，可能包含隐私内容。需求同时要求“实时预览”和“多张同时处理”。可选的架构有：浏览器本地处理、上传服务端处理、Electron 桌面端、以及混合方案。

## 决策

所有图片解码、渲染、编码都在浏览器内完成。交付物是纯静态站点，不包含任何服务端代码、对象存储或上传接口。

## 理由

1. 隐私：图片像素不离开设备，首屏即可承诺“不上传”。
2. 实时性：参数变化无需网络往返，预览可以做到 120ms 内。
3. 成本：零后端、零存储、零运维，静态托管即可。
4. 与需求匹配：批量水印是 CPU 密集型但可并行的小任务，现代浏览器足够。

## 后果

- 受浏览器内存与单线程性能限制，必须做并发控制和降采样预览。
- 批量导出需要 Worker + OffscreenCanvas，且要为 Safari 准备降级路径。
- 无法支持浏览器不能解码的格式（HEIC/AVIF），本期明确不支持。
- 无法做服务端审计、账号体系、云端历史。
- 单张 30MB / 单批 50 张的上限成为产品约束。

## 备选方案

- **上传服务端处理**：稳定、可处理超大图，但引入后端与隐私风险，且预览有往返延迟。
- **Electron 桌面端**：本地能力更强，但需要分发安装包，超出“静态托管”目标。
- **混合（小图本地、大图服务端）**：体验最好但复杂度最高，本期不做。
