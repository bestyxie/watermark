# ADR-0002：平铺水印的几何定义

- 状态：Accepted
- 日期：2026-10-28

## 背景

“间隔”只有在平铺重复时才有意义。需要精确回答：网格在哪个坐标系里排、从哪里开始、角度作用在谁身上、边缘怎么处理、多行文本算一个还是多个水印。

## 决策

### 坐标系与角度

- 画布坐标原点在左上，y 轴向下。
- 角度 `angle` 为顺时针为正，范围 -180°–180°，默认 -30°。
- 整个网格在旋转后的坐标系中排列，而不是“文字各自旋转、位置仍水平排列”。

### Tile 构造

- 多行文本属于**同一个 Tile**，行高 `1.2 × 字号`，水平居中、整体垂直居中。
- `tileWidth` = 最长行 `measureText().width`；`tileHeight` = `行数 × 行高`。

### 节距与原点

```text
f        = sizeRatio × min(W, H)
gap      = gapRatio × f
pitchX   = tileWidth  + gap
pitchY   = tileHeight + gap
```

- 网格以画布中心 `(W/2, H/2)` 为原点，对称向四周展开。
- 行与行对齐，不做交错。
- 间隔是相邻 Tile 包围盒的**边缘空隙**，不是中心距。

### 覆盖与裁切

- 令 `R = 0.5 × √(W² + H²)`（外接圆半径）。
- `rangeX = ceil(R / pitchX) + 1`，`rangeY = ceil(R / pitchY) + 1`；多出的一圈作为边界余量，保证旋转后四角都有 Tile。
- 绘制时先裁剪到画布，边缘 Tile 允许被截断。

### 绘制顺序

```text
translate(W/2, H/2)
rotate(angle)
for j, i:
  translate(i × pitchX, j × pitchY)
  draw lines centered at (0, 0)
  translate back
```

## 理由

- 先旋转坐标系再铺网格，才能得到视觉上“斜向成行”的平铺效果。
- 用外接圆半径决定遍历范围，是保证任意角度四角覆盖的最简充分条件。
- 多行合并为一个 Tile，避免行与行被间隔拆散。

## 后果

- 渲染复杂度与 Tile 数成正比；极端参数（1% 字号、0 间隔、超大图）可能产生数千个 Tile，需要上限保护。
- 文字宽度依赖 `measureText`，不同平台字体度量略有差异；预览与导出在同一设备完成，因此可接受。
- 不支持单个水印定位，也不支持交错平铺；这两项进入非目标。
- 无描边/阴影，浅色背景上的浅色水印可能不可见，由用户自行调色。
