# ADR-0004：批次共享单一规格，失败隔离

- 状态：Accepted
- 日期：2026-10-28

## 背景

需求是“单张、多张同时加水印”。多张时有两种可能：每张一套参数，或整批一套参数。逐图参数会显著增加状态模型、UI 和测试复杂度。

## 决策

1. 一个批次只有一个 `WatermarkSpec`，所有素材共享。
2. 不支持逐图覆盖，也不支持分组多套参数。
3. 导出开始时对 Spec 做深拷贝（冻结快照）；导出过程中的改参不影响当前任务。
4. 每张素材独立 `try/catch`：失败记录原因并继续，不终止整批。
5. 导出结束后展示“成功 N / 失败 M”，失败项可单独重试。

## 理由

- 批量水印的典型场景就是同一句声明、同一套样式，逐图配置是伪需求。
- 单一 Spec 让“调一次、全部同步”的实时预览变得简单且可预测。
- 冻结快照避免导出结果与用户看到的参数不一致。
- 失败隔离符合“批量”语义：一张坏图不应该毁掉另外 49 张。

## 后果

- 用户若确实需要两种水印，必须分两次导入/导出；这是有意接受的限制。
- 失败项重试需要一个稳定标识（`id`），不能用文件名（可能重名）。
- 状态上需要区分“批次状态”和“单张状态”，不能只维护一个全局 loading。
- 导出按钮的可用性取决于：有就绪素材、文本非空、无进行中的导出。

## 备选方案

- **逐图参数**：灵活但状态、UI、测试成本高，且与“实时预览全部同步”冲突。
- **分组多套参数**：面向专业排版，超出本期范围。
- **整批中止**：实现简单，但用户体验差，已否决。
